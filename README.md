# Red Owl Construction

Arabic and English MEP contracting portfolio. The complete offline site, company profile, photos and fonts are included in the v0.1.0 release archive. Extract the red-owl/assets directory from the release to use the source checkout locally.

Run `python3 export.py` after editing templates. Open index.html for the offline version or run `python3 server.py` for the local inquiry service. The published static version prepares an email draft.
